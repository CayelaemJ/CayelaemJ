04 · About the person and project

Why I built this

I am a data engineer, analytics engineer and full-stack builder who moved from statistics and BI toward the full system: source data, backend logic, interface, security and operating constraints. I enjoy understanding the connections between these pieces and helping others learn them.

I identify with the INTJ description as a personal shorthand for planning, independent investigation and systems thinking, not as a measure of intelligence or ability. I can contribute across much of software-oriented IT, while hardware engineering is not my specialist area.

Read The Person Behind the Code or my technical autobiography. The runnable lessons are in the public lab index.
